## 6. P2 diagnostic question family

P2 asks exactly five deterministic questions.

### P2-Q1 — turning-component localization

For every item, when:

`T_M == T_S`

classify whether both component identities also hold:

`A_corr_M == A_corr_S`

and:

`A_ctrl_M == A_ctrl_S`.

Allowed item classifications are exactly:

- `TURNING_COMPONENTWISE_IDENTITY`;
- `TURNING_EQUAL_BY_OFFSET_CANCELLATION`;
- `TURNING_DIFFERENT`;
- `TURNING_INVALID`.

`TURNING_EQUAL_BY_OFFSET_CANCELLATION` means `T_M == T_S` while at least one A component differs.

No tolerance-based near-equality class is permitted.

### P2-Q2 — coherence-summary localization

For every item classify exact persisted:

`C_M == C_S`

- `COHERENCE_EXACT_IDENTITY`;
- `COHERENCE_DIFFERENT`;
- `COHERENCE_INVALID`.

### P2-Q3 — endpoint-supporting state-hash identity

`matched_corr` versus `swapped_corr`

and:

`matched_ctrl` versus `swapped_ctrl`.

At each aligned coordinate compare exactly these four persisted hashes:

- `S_prev_sha256`;
- `G_sha256`;
- `W_sha256`;
- `S_post_sha256`.

For each item report:

- total aligned hash comparisons;
