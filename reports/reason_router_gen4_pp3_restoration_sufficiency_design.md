## State construction

Let `h` be the native frozen strong-channel state at the target token.

Define native PP3 coefficients:

`a = <h, pp3_plus>`

`b = <h, pp3_minus>`

Define the PP3 component:

`c3 = a*pp3_plus + b*pp3_minus`

Define the coefficient-transferred PP5 component:

`c5 = a*pp5_plus + b*pp5_minus`

`||c3||_2 = ||c5||_2`

neutralized background.
