## 1. Main result

The Mamba-1.4B behavioral failure is not well described as a narrow failure confined to
one baseline-margin region or one predicted class.

The more informative pattern is:

1. Mamba-370M's positive pair-level effect is strongly concentrated in weak/negative
   native-margin items and is carried primarily by `C2_NAME`;
2. Mamba-1.4B loses that `C2_NAME` benefit and is negative in both `C0_SHAM` and
   `C2_NAME`;
3. selected-plane coefficient magnitude and matched-control correction magnitude have
   opposite descriptive coupling with `D_BEH` across scales;
4. `q_authorized(restored-control)` is anti-correlated with correct-class margin effect
   at both scales, with the anti-coupling becoming very strong at Mamba-1.4B;
5. paired item-level scale differences are driven mainly by `C2_NAME`, while
   `C0_SHAM` is comparatively similar across scales.

The most compact descriptive interpretation is:

`370M C2-sensitive behavioral coupling does not survive scale-up to 1.4B.`

This is not a new inferential claim and does not replace the frozen primary test.

## 10. Scientific interpretation

The completed internal causal result remains:

`CORE-STABLE / RESIDUAL-PLASTIC STRENGTHENED THROUGH MAMBA-1.4B`

The completed behavioral result remains:

`SCALE_SPECIFIC_BEHAVIORAL_BRIDGE_ONLY`

This static analysis sharpens the relationship between them.

The 1.4B failure does not look like:

- a simple high-confidence saturation effect;
- a single predicted-class anomaly;
- a failure confined to one baseline-margin band;
- weak intervention magnitude.

Instead it is consistent with:

`core-stable internal causality + scale-dependent downstream coupling`

where the mapping from the frozen local causal component into the final task decision
reorganizes with scale.

The strongest descriptive evidence for this statement is:

1. the 370M bridge is carried mainly by `C2_NAME`;
2. the 1.4B `C2_NAME` effect becomes negative;
3. `C2_NAME` accounts for most of the paired cross-scale effect loss;
4. coefficient/correction magnitude coupling with behavior changes sign across scale;
5. `q_authorized` and correct-class margin become strongly anti-coupled at 1.4B.

This supports the existing "residual-plastic" interpretation at the behavioral
coupling layer, but does not establish a new universal rule.

## 12. Workflow rule carried forward

For later experiments, a static post-result analysis should be performed before moving
on when at least one of the following is true:

1. the primary endpoint fails;
2. only part of a multi-scale or multi-condition family passes;
3. the result changes sign across scale or condition;
4. the result is scientifically ambiguous despite valid execution;
5. existing frozen artifacts can distinguish plausible failure/coupling structures
   without new model responses;
6. the analysis can materially improve the interpretation or the next experiment's
   prospective design.

Do not create such an analysis merely as ritual when the result is already
unambiguous.

Default constraints for these analyses:

- reuse only frozen artifacts;
- zero new model forwards unless a new prospective experiment is separately
  authorized;
- zero new inferential p-values unless prospectively justified;
- no rescue;
- no post-hoc model/plane/layer/token/subset selection.
