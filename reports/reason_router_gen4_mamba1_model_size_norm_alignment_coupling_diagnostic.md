# ContraMamba Gen4 Mamba-1 Model-Size / Norm-Alignment Coupling Diagnostic

## Status

`STATIC_DESCRIPTIVE_SCALE_DIAGNOSTIC`

This report is a descriptive synthesis of already frozen five-scale Delta-L
readout evidence.

It introduces no model execution, training, backward pass, p-value, threshold
estimate, scaling-law fit, rescue, re-selection, or row filtering.

Tested nominal Mamba-1 scales:

`130M, 370M, 790M, 1.4B, 2.8B`.

Because only five sampled scales are available, all cross-scale correlations
below are descriptive diagnostics rather than inferential scaling-law evidence.

## Mechanistic variables

For each frozen readout row:

`Delta_L = g * n * h`

where:

- `g = ||task gradient||`;
- `n = matched native component norm`;
- `h = cosine(selected, gradient) - cosine(control, gradient)`.

The exact mean decomposition is:

`E[g n h] =
 mu_g * mu_n * mu_h
 + mu_g * Cov(n,h)
 + mu_n * Cov(g,h)
 + mu_h * Cov(g,n)
 + centered_three_way_term`.

The key candidate scale-dependent quantity is:

`NORM_GAP = mu_g * Cov(n,h)`.

A dimensionless companion is:

`corr(n,h)`.

## Non-monotonicity boundary

None of the following sequences is strictly increasing or strictly decreasing
across all five sampled scales:

- mean Delta-L;
- mean angular gap;
- NORM_GAP;
- corr(n,h);
- GRAD_GAP.

In particular, both NORM_GAP and corr(n,h) rebound between 1.4B and 2.8B.

Therefore no strictly monotonic scaling law is claimed.

## Mechanistic interpretation

The strongest cross-scale descriptive association is not between model size and
the mean Delta-L endpoint itself.

Instead, increasing sampled Mamba-1 scale is associated most consistently with
a shift in the relationship between native component magnitude and functional
angular alignment.

At the smaller sampled scales, larger component magnitude is weakly associated
with neutral or favorable selected-minus-control angular gap.

At the larger sampled scales, larger component magnitude is associated with
worse angular gap.

This state-magnitude / functional-alignment anti-coupling is directly relevant
to the previously frozen Delta-L autopsy:

- at 1.4B it reinforces an already negative average angular gap;
- at 2.8B it helps overturn a still-positive average angular gap.

The evidence therefore motivates the next hypothesis:

`MODEL SCALE -> REORGANIZATION OF NATIVE STATE MAGNITUDE / FUNCTIONAL ALIGNMENT COUPLING`

rather than the simpler hypothesis:

`MODEL SCALE -> MONOTONIC DELTA-L MAGNITUDE`.

The arrow above denotes a research hypothesis, not a demonstrated causal
relation.

## Scientific boundary

This diagnostic does not establish:

- statistical significance of a cross-scale correlation;
- a population-level scaling law;
- a continuous parameter-count threshold;
- strict monotonicity;
- semantic identity of plane labels across backbones;
- causality from parameter count to norm-alignment coupling;
- extrapolation beyond the five sampled Mamba-1 scales.

No p-values or model-size regression fits are added.
