## 5. Why the original controlled-v5 adaptation corpus is not reused as the
## sole contention population

The completed Phase 2 training used broad controlled-v5 final 3-way
classification pressure.

Under unrestricted C0, final learned R22 correction-map energy fractions were
only approximately:

- `5.89e-4`
- `1.30e-4`
- `1.77e-4`

across the three Phase 2 seeds.

Thus broad task adaptation did not naturally establish strong competition for
R22.

Phase 3 therefore uses a prospectively fresh XG1 mechanistic training
population where the already validated target-token intervention semantics are
defined explicitly.

This does not invalidate controlled-v5 as a task dataset.

It changes the scientific training-pressure question.

## 13. Contention metric

For unrestricted C0 after the final fixed training step, let:

`M = B_theta A_theta`

be the full linear correction map.

Define owner occupancy:

`F_R = ||R22^T M||_F^2 / ||M||_F^2`

Define matched-control occupancy:

`F_C = ||C22^T M||_F^2 / ||M||_F^2`

These are geometry diagnostics.

They do not use the causal-role assay population.

No p-value is computed during contention qualification.

---

## 14. Prospective contention gate

`PR` qualifies as genuine R22 contention only if every seed satisfies all of:

1. `F_R(PR) >= 0.005`
2. `F_R(PR) >= 10 * F_R(P0)`
3. `F_R(PR) >= 4 * F_R(PC)`
4. `F_R(PR) >= 4 * F_C(PR)`
5. training loss decreases from its exact step-0 value;
6. correction parameters remain finite;
7. all parent parameters remain byte-identical.

The `0.005` absolute floor corresponds to at least 0.5 percent of full
correction-map energy occupying the frozen two-dimensional causal-role
realization.

It is deliberately far above the observed Phase 2 unrestricted baseline.

This gate is a manipulation qualification rule.

It is not a scientific p-value.

If any seed fails, Phase 3 ends with:

`GEN5_PHASE3_CAUSAL_ROLE_CONTENTION_NOT_ESTABLISHED`

and no ownership confirmatory test is authorized.

No stressor-strength sweep is allowed.

No alternative PP plane is allowed.

No stressor rescaling after observing results is allowed.

## 21. Positive Phase 3 rule

A positive contention-conditioned ownership result requires:

1. Phase 3A contention qualification PASS;
2. `mean(Ibar_M1_PR) > 0`;
3. `mean(Q_RR_M1_PR) > 0`;
4. `mean(S_R_M1_PR) > 0`;
5. `mean(D_OWN_PR) > 0`;
6. `mean(D_INT) > 0`;
7. the single one-sided Student t-test on `D_INT` gives `p < 0.05`.

Positive label:

`GEN5_CAUSAL_ROLE_CONTENTION_REVEALS_STATE_UPDATE_OWNERSHIP_EFFECT`

Otherwise, after a valid Phase 3B execution:

`GEN5_CONTENTION_CONDITIONED_OWNERSHIP_EFFECT_NOT_ESTABLISHED`

A valid negative remains terminal for this exact Phase 3 design.
