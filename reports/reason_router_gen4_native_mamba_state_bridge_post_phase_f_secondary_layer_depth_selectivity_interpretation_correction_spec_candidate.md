## 3. Original overstrong implication

The frozen interpretation states, conditionally, that if at least one
prespecified Q1/Q3 NAME endpoint is supported:

SECONDARY_LAYER_NAME_LOCALIZATION =
SUPPORTED

and then states that this would establish that the midpoint-layer Phase F
dissociation is:

DEPTH_SELECTIVE

within the prespecified secondary-layer test.

The conditional result label itself may be retained only with the narrowed
meaning defined below.

The inference to formally established depth selectivity is too strong.

## 4. Statistical reason for correction

A supported test at a secondary layer together with a non-supported test at
the midpoint layer does not by itself establish that the effects at those
layers differ.

Formally:

SIGNIFICANT_AT_SECONDARY_LAYER
PLUS
NOT_SIGNIFICANT_AT_MIDPOINT

DOES_NOT_IMPLY

SIGNIFICANT_BETWEEN_LAYER_DIFFERENCE

A direct claim that the NAME response differs by depth would require an
explicit prespecified cross-layer contrast, interaction, or equivalent
between-layer statistical test under separate authority.
